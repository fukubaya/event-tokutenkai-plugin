特長とメリット

AIとコードを組み合わせることで、文字の崩れや曖昧さを排除し、 いつでもテキスト・配色・余白を変更可能な印刷用PDFを生成できます。

主な機能

  • 完全ベクター出力: 拡大しても文字や線が一切劣化しません。
  • テーマ一括変更: CSS変数を書き換えるだけで全体のトーン＆マナーを更新。
  • 正確なサイズ設計: A4/B5/mm指定、トンボ・断ち落としに対応。
  • CLI自動化: npx や uv から1コマンドでビルド可能。
